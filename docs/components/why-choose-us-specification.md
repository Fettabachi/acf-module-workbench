# Why Choose Us specification

- **Goal:** explain two to six meaningful differentiators with optional evidence.
- **Required fields:** section heading; claim and customer benefit for each reason.
- **Optional fields:** eyebrow, introduction, evidence text and public source per reason, one closing CTA, visual counter toggle, and desktop counter position.
- **Interaction:** informational reason rows; only explicit source and closing links are interactive.
- **Layout:** stacked editorial rows; evidence sits below the claim on narrow screens and beside it when space allows. Visible counters always occupy a top row on mobile; desktop counters can occupy a left column or top row. Hidden counters leave no visual gutter.
- **Editor:** ACF Block Version 3 expanded editor with introduction, reasons, and next-step tabs, plus collapsed-row summaries and Expand all / Collapse all controls.
- **Defensive rules:** omit incomplete rows, source links without evidence, and incomplete CTAs; require at least two complete reasons for public output.
- **Accessibility:** semantic section and ordered list, logical heading hierarchy, visible focus, and no frontend JavaScript.
- **Dependencies:** ACF text, textarea, button-group, tab, repeater, and link fields; WordPress block APIs; host semantic tokens and outer aligned width.
