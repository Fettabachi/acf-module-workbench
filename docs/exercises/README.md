the following format so future exercises are easy to review:

- exercise name and design source;
- goal and final PR-style summary;
- implementation commit;
- timing breakdown;
- architectural, accessibility, responsive, and editor decisions;
- tradeoffs, bottlenecks, and lessons for the next exercise.
